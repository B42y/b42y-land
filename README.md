# b42y-land

Ba2y landing page (Arabic and English).

## GitHub Pages

The [Pages workflow](.github/workflows/pages.yml) publishes the static site on every push to `main`. Before the first deployment, open [repository Pages settings](https://github.com/B42y/b42y-land/settings/pages) and set **Build and deployment → Source** to **GitHub Actions**. Then push the workflow to `main` (or run it from the Actions tab).

The default site URL is https://b42y.github.io/b42y-land/. The English page is at `/en/`. Site paths are relative so both pages work under the repository URL.
